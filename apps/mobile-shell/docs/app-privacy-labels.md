# App Store Privacy Labels

Last reviewed: 2026-08-17

Use these answers for App Store Connect > App Privacy.

## Tracking

- Data used to track the user: No
- App Tracking Transparency prompt required: No
- IDFA usage: No

## Data linked to the user

Declare these data types:

1. Contact Info > Email Address
   - Purpose: App Functionality, Developer's Advertising or Marketing
   - Used for tracking: No
   - Reason: social login/account identification may provide or store an email address; premium launch notifications can also be requested by email.

2. Contact Info > Phone Number
   - Purpose: Developer's Advertising or Marketing
   - Used for tracking: No
   - Reason: premium launch notifications can be requested by phone/contact number.

3. Identifiers > User ID
   - Purpose: App Functionality
   - Used for tracking: No
   - Reason: backend account/session identity.

4. User Content > Photos or Videos
   - Purpose: App Functionality
   - Used for tracking: No
   - Reason: users can upload a photo as feed/rest activity content.

5. User Content > Other User Content
   - Purpose: App Functionality
   - Used for tracking: No
   - Reason: users can submit feed/review text and hashtags.

6. Usage Data > Product Interaction
   - Purpose: App Functionality, Product Personalization
   - Used for tracking: No
   - Reason: rest recommendation inputs, selected rest activity starts, feed interactions, and plan-related app actions are tied to the signed-in account.

## Data not linked to the user

- None currently declared.

## Not collected

Do not declare these unless the app changes:

- Location
- Contacts
- Search History
- Browsing History
- Financial Info
- Health and Fitness
- Sensitive Info
- Purchases
- Audio Data
- Advertising Data
- Diagnostics
